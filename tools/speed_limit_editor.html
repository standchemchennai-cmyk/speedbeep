How to use
1. Click Draw segment.
2. Click the start and end of one reasonably straight stretch of road.
3. Set its verified speed limit. Use several segments for curves or limit changes.
4. Export CSV and import it into SpeedBeep.

Your work is autosaved in this browser's local storage. The editor is local; the basemap needs internet access. OpenStreetMap Standard is the default, with Esri and OpenTopoMap as fallbacks.
