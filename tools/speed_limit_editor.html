How to use
1. Import your current CSV or click Draw segment.
2. Click start and end points for one reasonably straight road stretch.
3. Routes remain visible: cyan = saved, yellow = selected.
4. Click a route or list entry to select it; drag the two yellow endpoint markers to refine it.
5. Export CSV and import it into SpeedBeep.

Work is autosaved in this browser. The basemap uses OpenFreeMap vector tiles and does not need an API key.
