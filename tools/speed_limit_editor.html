How to use
1. Your current bundled routes load automatically as 13 editable routes. To return to those routes, click Load bundled routes, or import another CSV.
2. Click the route start and end. New routes are automatically snapped to drivable roads.
3. For an imported straight route, select it and click Snap selected to road, or use Snap all to roads.
4. Cyan = saved route, yellow = selected. Dragging an endpoint marks it unsnapped until you snap it again.
5. Export CSV. Road shapes are converted into many short straight segments so the Android app can match them offline.

Work is autosaved in this browser, not sent to GitHub. Export CSV when finished and send that file back for inclusion in the next APK. Loading bundled routes replaces your current draft after confirmation. The map uses OpenFreeMap vector styles through MapLibre. Road snapping uses the public OSRM routing service and therefore needs internet access while editing.
